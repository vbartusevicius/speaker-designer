# Agent notes

- **Stack & layout:** Python 3.12 FastAPI app in `app/` (`app/main.py`, Pydantic request schemas in `app/schemas.py`). Physics in `app/physics/`, design/optimization/catalog/port/utils logic in `app/design/` (`models.py`, `systems.py`, `ports.py`, `utils.py`, `cabinet.py`, `layout.py`, `system.py`, `sub.py`, `tuner.py`, `optimizer.py`, `catalog.py`, `drivers_db.py`, `bem.py`, `spice.py`, `export.py`), frontend ES modules in `app/static/js/` (`state.js`, `svg.js`, `charts.js`, `catalog.js`, `start.js`, `design.js`, `build.js`, `main.js`), stylesheet `app/static/style.css`, CLI scripts in `scripts/`.
- **Package management & typing:** Poetry (`pyproject.toml`, `poetry.lock`, Poetry `2.5.1`). `Dockerfile` installs with `POETRY_VIRTUALENVS_CREATE=false` (`--only main` for release `DEV=0`, full dev group including `mypy` & `pytest` when `DEV=1`).
- **Driver catalog & pricing:**
  - Single unified readable catalog (`indent=2`): `app/data/drivers.json` (~1,312 drivers: curated EU-priced drivers with `curated: true` + `driver-base` CC BY 4.0 drivers with SoundImports URLs). `/api/optimize` and `/api/potential` filter to `price_eur > 0`.
  - `DriverRepository` (`app/design/drivers_db.py`, mtime-cached) + pluggable `ShopPriceProvider` strategies (`JsonLdProductProvider`, `AudiophonicsMicrodataProvider`, `register_price_provider()`) and `PriceCache` (`PRICE_CACHE_PATH`) in `app/design/catalog.py`; sync CLI in `scripts/sync_drivers.py`.
  - Custom drivers stored via `CUSTOM_DRIVERS_PATH` (default `userdata/custom_drivers.json`); measured FRD/ZMA via `MEASUREMENTS_PATH` (`app/design/measurements.py`).
- **Extension points:** `SpeakerSystem` protocol + `SYSTEMS` registry (`app/design/systems.py`, `register_system`), `ExportSpec` + `EXPORTERS` registry (`app/design/export.py`, `register_exporter`), `ShopPriceProvider` + `SHOP_PROVIDERS` (`app/design/catalog.py`).
- **Units & coordinates:** geometry in `mm`, volumes in `L`, physics internally SI (`m`, `m^2`, `m^3`). Driver DB entries require `nominal_mm` (never inches), `dims_verified`, and optional `shop {name, url, price_eur, in_stock, checked}`. Baffle origin is bottom-left of the LEFT speaker viewed from the front; right speaker is mirrored.
- **UI (`app/static/js/`):** 3-step flow (**1 Start** with 5 presets → **2 Design** full-width center-top controls + active driver cards + 2-up Baffle & Chart → **3 Build & export** with 4 tabs). ES modules share state/hooks via `state.js` (`actions`) with zero circular imports. `markChange()` groups one user action for deltas/Undo; `ensureCrossoverTuned()` auto-tunes crossover via `/api/tune` when entering Design/Build unless manually overridden (`state.xoManual`); SVG views must pass through `uniq()`; `placeMarks()` staggers close Plotly vertical line labels.
- **Optimization & verification endpoints:** `/api/tune` (`app/design/tuner.py`, Crossover only), `/api/maximize` (`_MaximizeSession` layout + port + crossover), `/api/potential` (`app/design/potential.py`), `/api/bem/start` (`app/design/bem.py`, `bempp-cl`, async 1 job at a time), `/api/spice` (`ngspice` installed in image).
- **Subwoofer mode:** `app/design/sub.py` (`SubwooferSystem` via `get_system("sub")`), endpoints `/api/sub/simulate|reverse`. Designs carry `system: "sub"` with no mid/tweeter/crossover; frontend uses `isSub()`, `renderSubDesign`, and `.sys-sub` / `.fr-only` / `.sub-only` CSS classes.
- **Public safety:** `READ_ONLY=1` blocks `POST`/`DELETE` on `/api/drivers*` and `/api/driver-base*`.
- **Commands:**
  - Local dev & test: `python3.12 -m venv .venv && .venv/bin/pip install poetry==2.5.1 && .venv/bin/poetry install && .venv/bin/pytest -q`
  - Docker run & test: `docker compose up -d --build` (`http://localhost:8000`) and `docker compose exec speaker-calc pytest -q`
  - Sync drivers: `python scripts/sync_drivers.py [--prices]`
  - CI/Release: `.github/workflows/ci-release.yml` syncs `app/data/drivers.json`, runs `mypy` + `pytest` inside Poetry Docker (`DEV=1`), publishes Docker Hub `${{ secrets.DOCKERHUB_USERNAME }}/speaker-enclosure-calc` tagged `YYYY.MM.DD.HHMM` + `latest`, and attaches `drivers.json` to the GitHub Release.
- **Browser verification:** Playwright against `http://localhost:8000` — verify zero `pageerror`/console errors and `document.documentElement.scrollWidth <= window.innerWidth`.
